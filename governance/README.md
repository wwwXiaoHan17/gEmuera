# Governance — Agent 自我进化机制

本目录是 gEmuera 项目的 **Agent 自我进化基础设施**：每次任务结束后把 AI 的表现、关键决策、
教训与用户提示词模式沉淀为可复用资产，让后续会话的任务效率逐步提升。

> **强制口径在 `AGENTS.md` 的「Agent 自我进化（governance）」一节**：触发判据、落盘截止点、
> 6 项要素、写法红线、沉淀阶梯、收尾自检均以那里为准。本文提供机制说明、记录模板与先例索引；
> 两者冲突时以 `AGENTS.md` 为准。
>
> 历史说明：`evolution-log/2026-08-16-quick-floating-panel.md` 中「临时沉淀」「精华已合并进预设」
> 等表述已被本机制取代，以 `AGENTS.md` 本节为准。

## 为什么需要它

- 本项目是 Vibe Coding（AI 主导开发）模式，会话之间互不共享上下文。
- 每次任务中踩过的坑（构建命令、平台限制、设计决策）不沉淀，下次会话会重复踩。
- 用户的提示词习惯（验证检查型、设想型、对齐型…）被识别后，Agent 可以按模式
  直接给出用户期望的输出结构，减少来回确认。
- **进化不是写日记**：记录 → 提示词模式 → 铁律 → 门禁/工具，逐层固化后下一次会话
  才能真正受益；只停在日志里等于没写。

## 目录结构

```text
governance/
├── README.md                # 本文件：机制总览、记录模板、先例索引
├── evolution-log/           # 任务复盘进化记录（每个有落地的任务一份）
│   └── YYYY-MM-DD-<任务简述>.md
└── prompt-patterns/         # 用户常用提示词模式库
    └── README.md
```

## 流程（触发判据与截止点见 `AGENTS.md` 本节）

1. **写进化记录**：`governance/evolution-log/YYYY-MM-DD-<任务简述>.md`；同一任务/同一 PR 的
   返工复审在原文件追加「复审/补遗（YYYY-MM-DD）」段，不新开文件。
2. **补充提示词模式**：发现新的用户提示词结构 → 追加到 `governance/prompt-patterns/README.md`
   （模式名 / 特征 / 应对策略，只增不改）。
3. **升级为铁律**：规范级、流程级教训 → 同一 PR 更新 `AGENTS.md` 或规范文档的**具体小节**。
4. **PR 引用**：PR 描述（无 PR 则最终交付消息）加一行
   `进化记录: governance/evolution-log/<文件名>.md`。

## 记录模板

6 项要素的判定标准见 `AGENTS.md`；下面只是骨架，标题可沿用既有写法（任务/根因/证据/Backlog 等），
但 6 项内容不可缺。**小任务每项写 1 行即可，不必凑长度**。6 项标准自 2026-11-03 起对新增/追加记录
生效，历史日志不追溯（旧记录缺项可用「补遗」补充，不改写原文）。

```markdown
# YYYY-MM-DD <任务简述>（H1 含日期与任务简述即可，格式不限）

## 任务目标与成果
## 关键决策与 Why
## 验证记录
## AI 表现复盘
## 教训 → 具体优化动作
## 遗留登记
```

（可删骨架之外的自加小节，如「复审与返工」「排除项」「环境障碍」；6 个必要项的内容不可缺。）

## 质量红线与原则

单次记录的判定（失守即不合格，任务视为未收尾）：

- 只写真实发生的事：不编造验证结论、不复制占位行、不把计划写成已完成。
- 验证结论必须带证据标签（`[实测]/[静态]/[未验证]`）且与描述一致。
- 教训必须落成可执行动作，"下次注意"式空话不算；遗留必须写"为什么不在本轮做"。
- 只记本任务改动，其他会话/其他 Agent 的未提交改动不得混入。
- 只增不改：修正已提交/已合并的历史用「补遗（日期）」段，不删改原文；未合并草稿可直接改。

长期原则：

- **格式轻量**：单文件 markdown，不建多级目录；但内容不轻——证据与教训必须具体。
- **可执行**：每条教训必须落成"下次怎么做"，而不是空泛评价。
- **不删历史**：进化记录只增不改，保证轨迹可追溯。

## 沉淀阶梯

evolution-log（过程资产）→ **prompt-patterns**（用户提示词模式）→ **AGENTS.md / 规范文档**
（首读铁律）→ **门禁 / 工具 / 测试**（自动化，不依赖记忆）。升级判据、"暂不自动化"与
"本轮暂不升级"的登记方式见 `AGENTS.md` 同名小节。
